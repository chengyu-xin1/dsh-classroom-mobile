# 验收清单：一项一项打勾

按顺序做，**哪一项没过就停下来查哪一项**，别跳着做。
前面的没过，后面的肯定过不了。

---

## 第一关：电脑自己能看到（1 分钟）

- [ ] 在电脑浏览器打开 `http://127.0.0.1:8765` → 应该看到页面，不是「无法访问」
- [ ] 打开 `http://127.0.0.1:8765/api/state` → 应该返回一段 JSON，里面有 `"port":8765`

**没过的意思**：程序本身没启动，或者端口不对。先解决这个，别管手机。

---

## 第二关：有公网地址了（2 分钟）

- [ ] 终端里 `cloudflared --version` 能打印版本号
- [ ] cloudflared 日志里有一行 `https://xxxx.trycloudflare.com`
- [ ] 日志里能看到 `protocol=http2`

**没过的意思**：
- 没有版本号 → cloudflared 没装好或没下完
- 地址是 `api.trycloudflare.com` → 抓错网址了，改成取最后一条
- 没有 http2 → 启动参数漏了 `--protocol http2`

---

## 第三关：在电脑上访问公网地址（2 分钟）

把下面的「你的地址」替换成实际网址，逐条敲：

```bash
# 1) 页面能打开，返回 200
curl -s -o /dev/null -w '%{http_code}\n' https://你的地址/

# 2) 不带密码，应该被拦住：401
curl -s https://你的地址/api/state

# 3) 带密码，应该通过：200
curl -s -H "X-Access-Pin: 你的6位数字" https://你的地址/api/state
```

- [ ] 第 1 条返回 `200`
- [ ] 第 2 条返回 `401`（**这是好事，说明锁生效了**）
- [ ] 第 3 条返回 `200`

**没过的意思**：
- 第 1 条超时 → 隧道没通，回第二关
- 第 2 条直接 200 → 密码锁没生效（多半是没判断 `cf-connecting-ip`）
- 第 3 条 401 → 密码不对，或者请求头名字拼错了

---

## 第四关：手机能装成 App（3 分钟）

- [ ] `https://你的地址/manifest.webmanifest` 返回 200
- [ ] `https://你的地址/sw.js` 返回 200
- [ ] 手机打开网址 → 输入一次密码 → 刷新后不再问
- [ ] iPhone：分享 → 添加到主屏幕；安卓：菜单 → 安装应用
- [ ] 从桌面图标打开 → 没有浏览器地址栏

**没过的意思**：
- 前两条 404 → 服务器还是旧程序，需要重启（只刷新页面没用）
- 图标打开是白屏 → 隧道地址变了，删掉图标重新添加

---

## 第五关：手机上真的能用（这一步才算数）

用**手机流量**打开（关掉 WiFi），依次确认：

- [ ] 页面能打开
- [ ] 输一次 6 位密码，之后不用再输
- [ ] 允许麦克风
- [ ] 录 30 秒，等 30～90 秒，出现一条带时间戳的文字
- [ ] 切到微信再回来，专注记录里能看到「离开 / 回来」
- [ ] 锁屏一分钟，再解锁 —— 确认你知道这期间录音会暂停（音频比实际时间短是正常的）

六项全打勾，才算交付完成。

---

## 最后一关：故意捣乱，确认不会崩（可选，5 分钟）

- [ ] 密码故意输错 → 每次都 401，绝不放行
- [ ] 把 cloudflared.exe 改名 → 程序给出「找不到 cloudflared」的中文提示，不是崩溃
- [ ] 把页面文件改名 → 访问首页返回明确的错误提示，不是一片白
