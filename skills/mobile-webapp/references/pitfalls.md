# 常见毛病对照表（像查感冒药一样查）

每条都写三件事：**你会看到什么** → **用人话说是怎么回事** → **怎么办**。
下面这些都是真踩过的，不是猜的。

---

## 1. 一运行就报 `spawn EPERM`

**你会看到**：`Error: spawn EPERM`，可在终端里手动敲同样的命令又是好的。

**人话**：有些运行环境（比如 AI 助手的工作区）不允许程序之间用「管道」传话，而 Node 默认就想用管道。

**怎么办**：把输出写进文件，再让程序去读文件。

```js
const fd = fs.openSync('out.log', 'w');
spawn(cmd, args, { stdio: ['ignore', fd, fd] });
```

---

## 2. 页面要转十几秒才出来

**你会看到**：电脑上秒开，手机上要等 14～16 秒；日志里一堆 `context canceled`、`no recent network activity`。

**人话**：校园网对一种叫 QUIC 的传输方式限速了。

**怎么办**：启动 cloudflared 时加 `--protocol http2`。日志里出现 `protocol=http2` 就是成功了。

---

## 3. 谁拿到网址都能进

**你会看到**：把网址发给别人，别人不用密码就能看你的数据。

**人话**：隧道是从你电脑本机转发出去的，服务器看到的永远是「自己访问自己」，于是一开始写的「只放行本机」判断把所有外网请求都放行了。

**怎么办**：看请求头里有没有 `cf-connecting-ip` / `cf-ray` / `x-forwarded-for`，有就当成「从外面来的」，必须验 6 位密码。

---

## 4. 关掉插件后端口一直被占

**你会看到**：程序退了，但 8765 还被占着；下次启动偷偷换成了 8766。

**人话**：浏览器和服务器之间那根「电话线」没挂断，服务器就不肯完全关闭。

**怎么办**：

```js
server.close(() => resolve());
server.closeAllConnections?.();   // 主动掐断所有连接
```

---

## 5. 换个网络后隧道报 `Tunnel not found`

**你会看到**：日志反复 `Tunnel not found`，状态还显示「正常」，但网址打不开了。

**人话**：免费隧道和旧网络的「登记信息」绑在一起，换网后旧登记失效了，重连时还在用旧号。

**怎么办**：把 cloudflared 进程杀掉，让程序重新拉一个，会生成**新网址**。别信缓存里的旧地址。

---

## 6. 下载下来的程序打不开

**你会看到**：`指定的可执行文件不是此操作系统平台的有效应用程序`。

**人话**：文件没下完（网断了），只下了一半。

**怎么办**：用镜像重新下（`ghfast.top` 或 `gh-proxy.com`），下完先看大小：Windows 版应该是 55,390,512 字节，再运行 `cloudflared --version` 确认。

---

## 7. 手机上麦克风没反应

**你会看到**：页面正常，一点录音就报错 `NotAllowedError` 或 `SecurityError`。

**人话**：浏览器规定，只有 `https://` 开头的地址才允许用麦克风，`http://10.x.x.x` 不行。

**怎么办**：用隧道给的 `https://` 地址录音；局域网 http 地址只能看，不能录。

---

## 8. 录下来的音频只有第一段能放

**你会看到**：ffmpeg 报 `Invalid data found when processing input`。

**人话**：录音软件切段的方式不对，后面的文件缺了「文件头」，播放器认不出来。

**怎么办**：每 30 秒完整停一次（`recorder.stop()`），上传，再重新开一段（`recorder.start()`）。这样每个文件都是完整的。停止录音时别忘了上传最后一段。

---

## 9. 一节课只录到开头两分钟

**你会看到**：上课 79 分钟，音频只有 2.5 分钟。

**人话**：手机一锁屏或切到别的 App，浏览器就把录音暂停了。这是手机的规定。

**怎么办**：在页面上明确写「上课期间请保持页面在前台、屏幕常亮」；用「离开/回来」记录去提醒用户，而不是假装能一直录。

---

## 10. 用 PowerShell 发中文变成乱码

**你会看到**：创建会话时，标题存进去是乱码或空的。

**人话**：老版 PowerShell 默认不用 UTF-8 编码发数据。

**怎么办**：测试改用 Node 的 `fetch`（它永远用 UTF-8），或者明确按 UTF-8 构造字节。**这是测试工具的问题，不要去改服务器。**

---

## 11. 程序拿到了一个假网址

**你会看到**：地址变成了 `https://api.trycloudflare.com`，然后所有请求都失败。

**人话**：cloudflared 启动日志里会打印它自己的官网域名，程序用正则找网址时先抓到了它。

**怎么办**：排除这几个固定前缀，并且取日志里**最后一个**匹配。

```js
const URL_RE = /https:\/\/(?!api\.|update\.|www\.|developers\.|blog\.)[a-z0-9][a-z0-9-]*\.trycloudflare\.com/gi;
const matches = text.match(URL_RE) || [];
const url = matches[matches.length - 1] || '';
```

## 12. 「安装到主屏幕」按钮不出现 / 装了是白屏

**人话**：手机对「能不能装成 App」有几条硬规定，缺一条就不给装。

**怎么办**，逐条对照：

- manifest 里必须有 `start_url`，而且不能写成相对路径
- Service Worker **不能缓存 `/api/` 开头的接口**，否则数据永远是旧的
- iPhone 只有在「添加到主屏幕」之后才会全屏打开，普通标签页不算
- 桌面图标里存的是当时的网址；隧道地址一变，图标就打开死页面，需要重新添加
